MY FORM — Personal Fitness & Wellness
======================================

WHAT'S INCLUDED
- Editable workout plan and exercise library
- Daily calories and protein logging
- Separate plain-water and other-fluid tracking
- Weight, sleep, pain and stiffness check-ins
- Editable medication reminder checklist
- Supplement log with a clinician/pharmacist clearance field
- Custom tracking field names
- Export/import JSON backup
- Local browser storage and basic offline cache when served over HTTPS

IMPORTANT LIMITATIONS
- This is a personal tracker, not medical advice or a medical device.
- The medication checklist is based on details previously reported by the user; verify every name, dose and timing with your current prescription and clinician.
- No cloud sync, account login, automatic push notifications, Apple Health integration, or App Store distribution is included.
- Local data may be lost if browser/site data is cleared. Export backups regularly.
- The offline service worker requires the app to be served over HTTPS (or localhost); opening index.html as a file is useful for previewing but does not enable full PWA/offline installation.

TRY IT
1. Open index.html in a modern browser to preview.
2. For an installable iPhone Home Screen web app, host the files on an HTTPS static host (for example, GitHub Pages).
3. On iPhone, open the hosted URL in Safari, tap Share, choose Add to Home Screen, turn on Open as Web App if offered, and tap Add.
4. Use Customize → Export backup regularly.

DATA
All daily data is stored in this browser on this device using localStorage. It is not encrypted or synced. Avoid storing sensitive information you would not want visible to someone with device access.
